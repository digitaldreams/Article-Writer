# Symfony Messenger

**Audience:** Symfony developers

**Reader level:** Intermediate

## Rough flow

Symfony Messenger Means a lot of configuration in the Yaml that days is over. Now its areally simple, a beginner developer will easily use the messenger easily. 

It has really great features. we will step by step processing a Order and use all of its features.  In the journey we will send Message to one platform and recieve to the other platform, We will create custom serializer and deseralizer, use custom stamp to use on our Receiver and sender that specify messages state.
