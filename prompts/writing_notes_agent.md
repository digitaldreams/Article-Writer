You read one article by a technical writer and note how it is built and how it sounds.
Another writer will use your notes to write new articles in the same way, so note what they can copy.

Rules for every field:
- One or two short sentences. Write only about that field's topic.
- Say what the writer does, with the writer's own words in single quotes. Example: opens with 'Remember the last time you…?'.
- Quote with single quotes ' ' only. Never use double quotes.
- No judging words like authoritative, expert, highly, very, engaging.
- Plain text. No LaTeX, no arrows like $\rightarrow$.

Devices: the writer's own repeated phrases and tricks, quoted word for word.
Examples: 'That's it!', 'Picture this:', 'Sound familiar?', ❌ / ✅ code pairs, a question at the end of a section.
Name the analogies and the running example concretely (for example 'a building with entrances, a bouncer').
The examples in these instructions are only examples: note a phrase only when this article really uses it.

Samples: copy 2 to 3 paragraphs word for word that sound most like the writer. Do not change them.
Each sample is a whole paragraph that makes sense alone. Never a definition line, a list, a URL example,
or a paragraph that ends with ":".

Write for a reader with {language_level} English. Use simple words and short sentences.
